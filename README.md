# 📈 Stock Price Prediction using Time Series Analysis

## Overview
This project demonstrates **time series forecasting** using historical stock prices of **Apple Inc. (AAPL)** from 2018–2023.  
We use **ARIMA, Prophet, and LSTM models** to predict future stock prices and visualize trends.

## Features
- Data collection from Yahoo Finance using `yfinance`  
- Exploratory Data Analysis (EDA) with trends and moving averages  
- Stationarity check using **ADF test**  
- Forecasting using:
  - **ARIMA** (traditional statistical model)
  - **Prophet** (Facebook's forecasting model)
  - **LSTM** (deep learning model for sequential data)  
- Visualizations of actual vs. predicted prices  

## Technologies Used
- Python
- Pandas, Numpy
- Matplotlib, Seaborn
- Statsmodels (ARIMA)
- Prophet
- TensorFlow/Keras (LSTM)
- Scikit-learn (MinMaxScaler)
